# Gestion des pédalos

Nouvelle interface responsive pour gérer 19 pédalos avec synchronisation Firebase.

## Fonctions

- Couleur physique de chaque pédalo
- Emplacement réservé pour la capacité (2 ou 4 places)
- Départs de 35 minutes et prolongation
- Arrivées et retards
- Alerte baignade
- Mise hors service et remise en service avec confirmation
- Recherche et filtres
- Compteur des locations du jour
- Mode démonstration sans modification de Firebase avec `?demo=1`

## Publication

Déposer les fichiers de ce dossier à la racine de la branche `main` de GitHub Pages.
