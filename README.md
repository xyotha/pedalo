# Application Pédalos V2

Fonctionnalités :
- Timer 35 minutes
- Prolongation +35 min
- Recherche
- Compteur locations du jour
- Alerte baignade par pédalo
- Reset quotidien silencieux sauf les cassés
- Bouton casser sécurisé
- Tri intelligent

Déploiement :
1. Va sur la branche V2-warning.
2. Remplace les fichiers par ceux du ZIP.
3. Commit.
4. Teste.
5. Merge vers main si tout est bon.
