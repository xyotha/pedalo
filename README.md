# Application Pédalos

Application simple pour gérer les départs et arrivées des pédalos.

## Fonctionnement

- 19 pédalos pré-enregistrés
- 30 minutes fixes
- Blanc = disponible
- Vert = en navigation
- Rouge = en retard
- Gris = cassé
- Synchronisation temps réel avec Firebase
- Compatible GitHub Pages
